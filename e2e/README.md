# Сквозные проверки в браузере

Сценарии для ручного запуска против dev-сервера (Playwright, Chromium).
В `npm run check` не входят: им нужны запущенные бэкенд и Vite.

```bash
# 1. Учитель, три ученика и класс в dev-базе (пароль у всех Kot12345e2e)
cd backend && sh scripts/with-env.sh npx tsx ../e2e/setup.mts   # печатает {"classId": ...}

# 2. Серверы — см. HANDOFF.md, раздел 6 (бэкенд :3000, Vite :5173)

# 3. Сценарий урока (этап 4.1): режимы, рука, мел, очистка, «Следуйте за мной»,
#    лазер, скрытие курсоров, диалог доступа. Снимки экрана — в $E2E_OUT (по умолчанию /tmp).
node e2e/lesson.cjs <classId>

# 4. Сценарий заданий (этап 4.2): раздача, главная ученика, сдача, сетка работ,
#    пометки и отметка учителя, возврат на доработку, миниатюры в списке досок.
node e2e/assignments.cjs <classId>

# 5. Сценарий рисования (этап 5.1): живой штрих у другого участника, маркер под
#    пером, распознавание фигуры, права ластика, попиксельный ластик, отмена жеста.
node e2e/drawing.cjs <classId>

# 6. Сценарий файлов (этап 5.2a): картинка инструментом, из буфера и перетаскиванием,
#    обрезка, PDF из двух страниц как фон, ученик видит страницу PDF и пишет поверх.
node e2e/media.cjs <classId>

# 7. Сценарий текста (этап 5.2b): заголовок, жирный, цвет, формулы ($…$ и диалог),
#    таблица; ученик видит текст и пишет поверх; «Редактирует …»; текст из буфера.
node e2e/text.cjs <classId>

# 8. Сценарий формул (этап 5.3a): формула из палитры и с клавиатуры, правка двойным
#    щелчком, блок «Решение» из трёх шагов с отметками проверки, Ctrl+K «дискриминант».
node e2e/formula.cjs <classId>

# 9. Сценарий калькулятора и распознавания (этап 5.3b): единицы, переменные, история,
#    пересчёт двойным щелчком, рукопись → формула, Ctrl+Z, ученик считает без записи.
#    Бэкенд запускать с FORMULA_OCR_URL=http://127.0.0.1:8599/predict — подставной
#    сервис распознавания на этом порту поднимает сам сценарий.
node e2e/calc.cjs <classId>

# 10. Сценарий планиметрии (этап 6.1a): инструменты из раздела на панели, отрезок и
#     треугольник на общих точках, перетаскивание точки (ученик видит перестроение),
#     Ctrl+Z, окружность протяжкой, удаление точки вместе с построениями.
node e2e/planimetry.cjs <classId>

# 11. Сценарий построений (этап 6.1b): центр тяжести и описанная окружность щелчком
#     по треугольнику, отметка угла, перестроение у ученика, осевая симметрия
#     выделенного треугольника (A′B′C′), точка на окружности тянется вдоль неё.
node e2e/constructions.cjs <classId>

# 12. Сценарий чертёжных инструментов (этап 6.1c): линейка повёрнута ручкой с Shift,
#     перо вдоль края — ровная линия, луч транспортира на 60°, циркуль: раствор
#     грифелем, полный оборот — окружность с центром в точке, её видит ученик.
node e2e/drafting.cjs <classId>

# 13. Сценарий графиков (этап 6.2a): G — оси и график с параметрами, слайдер у ученика,
#     неравенство на тех же осях, правка двойным щелчком, таблица значений,
#     числовая прямая, тригонометрическая окружность.
node e2e/graphs.cjs <classId>

# 14. Сценарий анализа на графике (этап 6.2b): нули и экстремумы параболы, касательная
#     с ручкой (ученик видит), площадь, суммы Римана (n с панели), Тейлор для 2sin x.
node e2e/calculus.cjs <classId>

# 15. Сценарий аналитической геометрии (этап 6.3a): гипербола по уравнению, прямая,
#     точка и расстояние до прямой, векторы протяжкой и их сумма у ученика.
node e2e/analytic.cjs <classId>

# 16. Сценарий линейной алгебры (этап 6.3b): матрицы в диалоге, A·B и det A с пересчётом
#     у ученика после правки A, метод Гаусса для системы 3×3, линейное преобразование.
node e2e/linalg.cjs <classId>

# 17. Сценарий стереометрии (этап 6.4a): куб инструментом, 3D-редактор (объёмный вид
#     three.js), поворот виден ученику по ходу жеста, ребро и второе тело, Ctrl+Z одним
#     шагом, «Отмена»; ученик вращает сцену учителя только у себя; «Следуйте за мной»
#     поворачивает открытую у ученика сцену; все 9 видов тел инструментами.
node e2e/stereo.cjs <classId>

# 18. Сценарий построений в пространстве (этап 6.4b): в 3D-редакторе щелчками — сечение
#     куба через середины трёх рёбер (шестиугольник), диагонали граней AB₁ и BC₁,
#     ρ = 4√3/3 и угол 60° между ними, доля ребра для точки K; у ученика всё видно;
#     развёртка куба; плоский чертёж (точки и отрезки планиметрии), Ctrl+Z — одним шагом.
node e2e/stereo-space.cjs <classId>

# 19. Сценарий общих инструментов физики (этап 7.1a): опора и брусок на ней, масштаб
#     в диалоге, сила тяжести и реакция опоры от точек привязки бруска, обозначения mg и N,
#     смена масштаба пересчитывает векторы, равнодействующая трёх сил, проекции на
#     повёрнутые оси; ученик видит всё.
node e2e/physics-common.cjs <classId>

# 20. Сценарий «Дано / Найти / Решение» (этап 7.1b): столбец СИ по ходу набора (500 г → 0,5 кг),
#     F·m — «Размерность не сходится», F/m — «a = 4 м/с² ✓», постоянная g из списка
#     (P = m·g = 4,9 Н), постоянная Планка из Ctrl+K, график v(t) = 2 + 3t с подписями осей.
node e2e/physics-given.cjs <classId>
```

Сервер ограничивает частоту входов (`RATE_LIMIT_LOGIN_PER_MINUTE`, по умолчанию 10 в минуту с одного IP). Если запускать все сценарии подряд, последний может получить 429 на входе: делайте паузу в минуту или поднимите предел в локальном `.env`.
