# Учебная доска

Интерактивная бесконечная доска для совместных занятий учителя и учеников по математике и физике.
Покрывает школьный курс (5–11 классы, ОГЭ/ЕГЭ, олимпиады) и университетский. Интерфейс на русском языке.

> **Статус: этап 3.3 из 9.** Готовы авторизация, панель администратора, доски и папки, сервер реального времени с проверкой прав, ядро холста (фоны, страницы, фигуры, выделение, трансформации, группы, слои, блокировка, копирование, отмена своих действий), курсоры и участники, работа без сети, привязки, поиск Ctrl+K и справка «?». Дальше — режимы урока и права учителя (этап 4).
> Полная инструкция по развёртыванию на Ubuntu 24.04 появится на этапе 9.

## Разработка

Нужны Node.js 22 или новее и PostgreSQL 16. Локально подойдёт `apt install postgresql` или контейнер `postgres:16`.

```bash
# 1. База данных (один раз)
sudo -u postgres psql -c "CREATE USER doska WITH PASSWORD 'doska' CREATEDB;"
sudo -u postgres createdb -O doska doska        # основная
sudo -u postgres createdb -O doska doska_test   # для тестов

# 2. Настройки: скопируйте пример и заполните
cp .env.example .env
#   для разработки:
#   NODE_ENV=development
#   DATABASE_URL=postgresql://doska:doska@localhost:5432/doska?schema=public
#   JWT_ACCESS_SECRET=<openssl rand -base64 48>
#   PUBLIC_ORIGIN=http://localhost:5173,http://localhost:3000
#   COOKIE_SECURE=false
#   SEED_ADMIN_PASSWORD=<пароль с буквой и цифрой, без логина внутри>

# 3. Установка, миграции, первый администратор
npm install
npm run build:shared
npm run db:migrate
npm run db:seed

# 4. Запуск (в двух терминалах)
npm run dev:backend    # API: http://localhost:3000, проверка: /api/health
npm run dev:frontend   # интерфейс: http://localhost:5173 (проксирует /api на бэкенд)

# Проверки
npm run check   # типы + тесты (shared и backend) + сборка + схема Prisma
npm test
```

Войдите под администратором из `SEED_ADMIN_LOGIN` и `SEED_ADMIN_PASSWORD`. При первом входе система попросит сменить пароль.

Тесты бэкенда используют отдельную БД. Адрес задаётся переменной `TEST_DATABASE_URL`, по умолчанию `postgresql://doska:doska@localhost:5432/doska_test`; миграции применяются к ней автоматически.

### Рисование

- **Перо (P):** толщина зависит от нажатия стилуса, линия сглаживается, другие участники видят штрих, пока он рисуется. Толщина задаётся в экранных пунктах и сохраняется в мировых единицах: при увеличенном масштабе перо пишет тоньше.
- **Распознавание фигур:** если задержать перо в конце штриха (0,6 с), он превращается в отрезок, прямоугольник, эллипс (окружность), треугольник или четырёхугольник. Выключается флажком на панели пера.
- **Маркер (M):** полупрозрачный, ложится под уже нарисованное.
- **Ластик (E):** «Объекты целиком» стирает всё, чего коснулся, «Части штрихов» разрезает штрихи пера и маркера. Ластик стирает только то, что разрешено правами. Весь жест — один шаг отмены.

### Текст и формулы

- Инструмент «Текст» (T) создаёт блок; двойной щелчок по блоку открывает редактор. На панели над блоком: стиль абзаца (текст, заголовки 1–3), размер шрифта, жирный, курсив, подчёркнутый, зачёркнутый, цвет, списки, выравнивание, формула, таблица (вставить, добавить или удалить строку и столбец).
- Формулу можно набрать в тексте между знаками доллара (`$x^2$`) или вставить кнопкой Σ — откроется редактор формул (см. ниже). Двойной щелчок по формуле — изменить её.
- Обычный текст из буфера (Ctrl+V на доске) становится новым блоком.
- Пока блок открыт, другие видят на нём «Редактирует …» и не могут открыть его сами. Вся правка блока отменяется одним Ctrl+Z.

### Формулы

- **Формула (F)** — отдельный объект на доске. Редактор — MathLive: визуальный ввод с быстрыми сочетаниями (`sqrt`, `frac`, `alpha`, `int`, `sum`, `lim`, `->`, `<=>`, `+-`, `deg`, `RR`), Tab — к следующему месту ввода, Enter — сохранить. Над полем — палитра шаблонов по темам: основное, алгебра, тригонометрия, анализ, векторы и матрицы, множества и логика, греческие буквы, физика. Есть экранная клавиатура и режим «Код LaTeX». Растяжение рамкой меняет кегль. Двойной щелчок — изменить.
- **Решение (Shift+F)** — блок пронумерованных шагов: формула и комментарий к каждому, порядок шагов меняется стрелками. Если включена проверка, между шагами ставятся отметки: ✓ — переход равносилен (проверено подстановкой случайных чисел), ✗ — выражения не равны, ? — автоматически не проверено (неравенства, интегралы, неравносильные преобразования уравнений и т. п.). Это подсказка, а не доказательство.
- Шаблоны палитры ищутся в Ctrl+K по названию и ключевым словам («дискриминант», «интеграл»…): готовая формула ставится в центр экрана.
- **Калькулятор (C)** — панель рядом с доской, считает по мере набора. Десятичная запятая, аргументы через «;», функции sin, cos, tg, ctg, lg, ln, log(8; 2), √, градусы °. Единицы по-русски: «2 кг * 9,8 м/с^2» = 19,6 Н; перевод — «в»: «72 км/ч в м/с». Переменные: «x = 5», затем «x^2». Enter — в историю. «На доску» ставит формулу «запись = результат» (объект «Вычисление»), двойной щелчок по ней — пересчитать. Считать может любой участник, ставить результат — тот, у кого есть право записи. Если выделена формула, калькулятор открывается с ней.
- **Распознавание рукописных формул:** выделите штрихи пера и нажмите «Распознать формулу» на панели свойств (или найдите команду в Ctrl+K). Распознанная запись открывается в редакторе — её можно поправить. Формула встаёт на место рукописи и заменяет её; Ctrl+Z возвращает рукопись. Работает, если на сервере задан `FORMULA_OCR_URL` (см. ниже).
- Редактор формул и math.js загружаются отдельными частями при первом использовании и не замедляют открытие доски.

#### Сервис распознавания формул

Свой контейнер на pix2tex (LaTeX-OCR, только процессор) в `services/formula-ocr`. Рукописи учеников не уходят во внешние сервисы.

```bash
docker compose --profile ocr up -d formula-ocr       # первая сборка скачивает PyTorch и веса модели (~2 ГБ)
# в .env бэкенда:
FORMULA_OCR_URL=http://127.0.0.1:8502/predict
FORMULA_OCR_API_KEY=                                 # необязательно; тот же ключ получает контейнер
npm run test:ocr                                     # проверка HTTP-обёртки (Python 3, без модели)
```

Протокол простой: `POST` с телом PNG (`Content-Type: image/png`) и заголовком `Authorization: Bearer <ключ>`, если ключ задан. Ответ — JSON `{"latex": "…"}` или просто строка JSON. Поэтому вместо своего контейнера можно указать любой совместимый сервис. Пустой `FORMULA_OCR_URL` выключает функцию: кнопка не показывается.

| Метод | Путь | Назначение |
|---|---|---|
| GET | `/api/formula-ocr` | `{enabled}` — включено ли распознавание |
| POST | `/api/formula-ocr` | тело — PNG до 2 МБ; ответ `{latex}`; не больше 20 запросов в минуту на пользователя |

### Планиметрия

Кнопка «Планиметрия» на панели инструментов раскрывает список: точка (Shift+P), отрезок, луч, прямая, вектор, ломаная, многоугольник, правильный многоугольник, окружность, дуга, сектор, сегмент круга, эллипс. Все они есть и в Ctrl+K.

- Фигура строится щелчками по точкам; отрезок, окружность и другие фигуры из двух точек — ещё и протяжкой. Щелчок по существующей точке (она подсвечивается привязкой) использует её. Новые точки подписываются A, B, C…, после Z — A₁, B₁…
- Ломаная завершается щелчком по последней точке или Enter, многоугольник — щелчком по первой точке. Backspace убирает последнюю точку, Esc отменяет построение.
- Дуга, сектор и сегмент: центр, начало дуги, конец (против часовой стрелки). Эллипс: центр, конец полуоси, точка, задающая вторую полуось. Число сторон правильного многоугольника — на панели свойств инструмента.
- **Динамическая геометрия:** потяните точку — все фигуры на ней перестроятся, у всех участников сразу. Перетаскивание фигуры двигает её точки. Весь жест отменяется одним Ctrl+Z.
- При удалении точки, на которой построены фигуры, доска спрашивает «Удалить вместе с построениями?». Точки, созданные вместе с фигурой, уходят вместе с ней. При копировании фигура копируется со своими точками.
- На панели свойств: цвет, толщина, вид линии, подпись, заливка замкнутых фигур, «Размер» (длина, радиус, площадь в клетках сетки).

**Построения** (кнопка «Построения»): середина (две точки или щелчок по отрезку), точка пересечения (две линии или щелчок прямо в пересечение), точка на объекте (её тянут вдоль линии, выделять не нужно), перпендикуляр и параллельная (точка, затем прямая), биссектриса угла (точка, вершина, точка), серединный перпендикуляр, касательные из точки к окружности, медиана и высота (вершина, затем концы противоположной стороны), точки пересечения медиан (M), высот (H), центры вписанной (I) и описанной (O) окружностей, сами эти окружности — для них достаточно щёлкнуть по треугольнику. Подсказка у курсора говорит, что выбрать дальше; Esc начинает заново.

**Преобразования** (кнопка «Преобразования»): осевая и центральная симметрия, поворот (угол — на панели инструмента), параллельный перенос на вектор, гомотетия (коэффициент — на панели). Выделите фигуры заранее или щёлкните по одной, затем укажите ось, центр или вектор. Образ следует за оригиналом; вершины образа подписываются A′, B′, C′.

**Отметки и измерения** (кнопка «Отметки и измерения»): отметка угла (точка, вершина, точка) с величиной в градусах, число дуг, угол больше 180°, прямой угол — квадратиком; штрихи равных отрезков (1–3); «Размер» — щелчок по фигуре показывает или прячет её размер.

**Чертёжные инструменты** (кнопка «Чертёжные инструменты»): щелчок ставит инструмент на доску (на странице по одному каждого вида, повторный выбор переносит его к щелчку). Их видят все участники; двигают выделением, убирают — Delete, учитель закрепляет — Ctrl+L.
- **Линейка:** деления в клетках сетки, поворот — круглой ручкой на правом конце (Shift — шаг 15°), ноль прилипает к точкам. Перо или маркер, начатые у края линейки, рисуют ровную линию вдоль него.
- **Транспортир:** шкалы в обе стороны, центр прилипает к точкам, поворот — ручкой справа. Синий луч-указатель тянут за точку — он показывает угол по шкале (Shift — целые градусы).
- **Циркуль:** игла ставится на точку, раствор задаётся грифелем (прилипает к точкам), синяя ручка над шарниром вращает циркуль и чертит дугу; полный оборот — окружность. Начерченное — обычные дуга и окружность планиметрии с центром в точке под иглой.

Все построения динамические: потяните вершину — перестроится вся цепочка. Удаление точки удаляет и всё, что на ней построено (после подтверждения).

### Графики и анализ

Кнопка «Графики и анализ» на панели инструментов: система координат, график (G), слайдер, таблица значений, числовая прямая, тригонометрическая окружность.

- **График (G):** щелчок по системе координат строит график на ней, щелчок мимо — создаёт оси с центром в точке. В диалоге — одна строка, вид определяется по записи: `y = x^2 - 2x - 3` или просто `x^2 - 2x` — функция; `x^2 + y^2 = 16` — кривая F(x, y) = 0; `y > x^2`, `x² + y² ≤ 9` — неравенство (область закрашена, граница строгого — пунктиром); `(3cos(t); 2sin(t))` — параметрическая кривая; `r = 2(1 + cos(t))` — полярная. Десятичная запятая, умножение можно не писать (2x), функции sin, cos, tg, ctg, ln, lg, sqrt, abs, exp, √, ², π. Двойной щелчок по графику — изменить запись.
- **Параметры:** буквы кроме x, y, t (a, b, k…) — параметры. Для них под осями сами появляются слайдеры; потяните бегунок — график меняется у всех. Слайдер можно поставить и отдельно — графики, которые ждали этот параметр, подключатся к нему.
- **Система координат:** протяжкой — область нужного размера, щелчком — стандартная. Пределы осей и сетка — на панели свойств; растяжение рамкой меняет размер, пределы сохраняются. Перетаскивание графика двигает его оси.
- **Таблица значений:** щелчок по графику функции — таблица x и y справа от осей; начало, шаг и число строк — на панели свойств.
- **Числовая прямая:** множество записывается на панели свойств: `[-2; 3) ∪ (5; +∞)`, точки — `{1; 4}`. Закрашенный кружок — точка входит, пустой — нет.
- **Тригонометрическая окружность:** точку угла тянут по окружности (прилипает к π/6, π/4…, Shift — шаг 15°), показываются sin, cos и, по желанию, tg с величинами.
- math.js для графиков загружается при первом графике на доске.

**Анализ на графике** (кнопка «Анализ на графике»): щелчок по графику функции y = f(x) ставит:
- **точку на графике** с координатами (её тянут вдоль графика сразу, без выделения);
- **нули функции**, **экстремумы** (max/min), **точки пересечения** двух графиков (щелчок по одному, затем по другому) — находятся сами и следуют за слайдерами;
- **касательную** с уравнением и k = f′(x₀) (символьная производная) и **секущую** через две точки с k = Δy/Δx — точки тянут ручками;
- **площадь** под графиком или **между графиками** на [a; b] со значением интеграла, пределы — ручками на оси x;
- **суммы Римана**: левые, правые, средние, трапеции; число отрезков — ползунком на панели свойств, рядом — точное значение интеграла;
- **ε-δ**: полосы ε вокруг предела и δ вокруг точки, ширина — ручками; надпись говорит, выполняется ли условие;
- **многочлен Тейлора** выбранной степени в точке x₀ (с записью многочлена) и **частичную сумму ряда Фурье** с выбранным числом слагаемых по периоду [a; b].
Все эти объекты перестраиваются вместе с графиком (слайдеры, правка записи). На неравенствах и неявных кривых они не строятся — только на функциях.

### Аналитическая геометрия

Кнопка «Аналитическая геометрия»: работает на системе координат раздела «Графики и анализ» (щелчок мимо осей создаёт их).

- **Прямая по уравнению:** любая запись — `2x − 3y + 6 = 0`, `y = 2x − 1`, `x = 3`; на доске — уравнение в виде Ax + By + C = 0 с целыми коэффициентами, по желанию — нормальный вектор n(A; B) и направляющий a(−B; A). Параметры (k, b…) — слайдеры.
- **Кривая второго порядка:** каноническое или общее уравнение (`x²/25 + y²/9 = 1`, `x² + y² − 4x + 6y − 12 = 0`, `x·y = 4`, `y² = 8x`). Доска определяет вид (эллипс, окружность, гипербола, парабола, вырожденная или мнимая), приводит к каноническому виду (с центром и поворотом осей, если нужно), показывает a, b, c, e, p, фокусы, директрисы и асимптоты (включаются на панели свойств).
- **Точка по координатам** и **вектор с координатами** (протяжкой от начала к концу) — координаты прилипают к половинам клетки (Alt — без привязки); точку и концы вектора тянут сразу, без выделения.
- **Сумма и разность векторов** (правило треугольника или параллелограмма), **умножение на число**, **скалярное произведение** с углом между векторами; **расстояние от точки до прямой** с формулой и перпендикуляром; **угол между прямыми** и точка их пересечения.

### Картинки и PDF

- Картинку можно вставить из буфера (Ctrl+V), перетащить файл на доску или выбрать инструментом «Картинка или PDF» (I). Перед загрузкой браузер поворачивает снимок по EXIF и уменьшает до 4096 пикселей по стороне; сервер проверяет файл по содержимому и удаляет метаданные. Кнопка «Обрезать» на панели свойств меняет видимую часть, сам файл остаётся прежним.
- PDF добавляется новыми страницами доски (по одной на страницу PDF) с PDF в качестве фона. Страницы рисуются в браузере в масштабе экрана, поэтому текст чёткий при любом увеличении.
- Файлы хранятся в MinIO (`S3_ENDPOINT` и ключи) или, если `S3_ENDPOINT` пуст, в каталоге `UPLOADS_DIR`. Пределы размера — `UPLOAD_MAX_IMAGE_MB` и `UPLOAD_MAX_PDF_MB`.

| Метод | Путь | Назначение |
|---|---|---|
| POST | `/api/boards/:id/assets` | загрузить файл (тело — файл целиком, имя — заголовок `X-File-Name`); нужно право записи на доске |
| GET | `/api/assets/:id` | содержимое файла (нужен вход) |
| GET | `/api/assets/:id/info` | тип, размер, размеры картинки |

### Задания

| Метод | Путь | Назначение |
|---|---|---|
| GET / POST | `/api/assignments` | задания учителя со счётчиками; раздать копии доски `{title, instructions, templateBoardId, classId, studentIds, dueAt}` |
| GET | `/api/assignments/mine` | задания ученика (его работы, статусы, отметки) |
| GET / PATCH / DELETE | `/api/assignments/:id` | задание и работы; название, описание, срок, `closed`; удалить вместе с работами |
| POST | `/api/assignments/:id/students` | выдать ещё ученикам `{studentIds}` или новым ученикам класса `{fromClass: true}` |
| POST | `/api/works/:id/submit`, `/unsubmit` | сдать работу, отменить сдачу (ученик) |
| POST | `/api/works/:id/review`, `/return` | проверено `{grade}`, вернуть на доработку (учитель) |

Учитель раздаёт задание из меню «Урок» на доске или из меню карточки доски. Каждый ученик получает свою копию доски в её текущем виде. На странице задания — сетка работ с живыми миниатюрами и фильтр по статусу. В работе ученика учитель пишет пометки красным (ученик их не изменит), ставит отметку и при необходимости возвращает работу на доработку. Ученик видит задания на главной странице, сдаёт работу кнопкой «Сдать работу»; сданную работу он не меняет. Свой конспект ученик может открыть учителям своих классов (меню карточки).

### Урок

Учитель управляет уроком кнопкой «Урок» в шапке доски:
- режим одной кнопкой: «Лекция» (пишет учитель), «Совместная работа» (пишут все), «Выборочно» (пишут ученики с мелом);
- «Следуйте за мной»: вид учеников (страница, область доски, камеры 3D-сцен) следует за учителем; в строгом режиме ученик не может отойти;
- очистка записей учеников на странице или на всей доске (перед очисткой сохраняется версия);
- настройки доски и диалог «Доступ к доске…» (классы, отдельные ученики, соведущие, учителя «только просмотр»).

В списке участников учитель даёт и забирает мел и удаляет записи конкретного ученика. Ученик поднимает руку кнопкой в шапке; учитель слышит сигнал и видит счётчик рук. Лазерная указка (K) видна всем и угасает за 1,5 с.

### WebSocket `/ws/boards/:id`

Это протокол Yjs (sync и awareness) с управляющими сообщениями; описание — в [docs/SYNC_PROTOCOL.md](docs/SYNC_PROTOCOL.md).
Сервер применяет каждое изменение, проверяет права и запрещённое сразу отменяет у всех. Документы сохраняются в PostgreSQL: журнал изменений пишется раз в секунду и регулярно сжимается в снимок.

Формат CSV для импорта: колонки «ФИО; Логин; Роль; Класс», разделитель `;`, `,` или табуляция, заголовок необязателен.
Логин и роль можно не указывать: логин сгенерируется из ФИО, роль возьмётся по умолчанию.
Импорт атомарный: при любой ошибке в файле не создаётся никто.
Временные пароли возвращаются только в ответе на создание, импорт или сброс; в базе хранятся лишь хеши.

Все изменяющие запросы к `/api` должны передавать заголовок `X-CSRF-Token` со значением cookie `csrf_token`, а их `Origin` должен входить в `PUBLIC_ORIGIN`.
Ошибки возвращаются в формате `{"error": {"code", "message", "details?"}}`.
